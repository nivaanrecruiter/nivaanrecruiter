# Nivaan Recruitment Website Starter

A responsive, multi-page recruitment website built with plain HTML, CSS and JavaScript. No build step or framework is required.

## Pages
- `index.html` — home page
- `jobs.html` — job board with client-side search and category/location filters
- `job-details.html` — job detail template, populated from the selected sample job
- `apply.html` — candidate application form
- `employers.html` — recruitment services for employers
- `about.html` — about page
- `contact.html` — enquiry form
- `privacy.html` — privacy policy starter template
- `terms.html` — terms starter template

## Run locally
Open `index.html` in a browser, or serve this folder using any static web server.

## Before launch
1. Replace sample job listings with real, authorized vacancies.
2. Replace demo email, office/service area and company details.
3. Connect application and contact forms to a secure backend or form provider. At present, forms do not transmit or store submissions.
4. Review the privacy policy and terms with a qualified professional for your jurisdiction.
5. Add your real social links, verified testimonials and actual service details only.
6. Configure HTTPS and your domain with your chosen hosting provider.
7. If you want employer logins, recruiter dashboards, CV upload/storage, job posting administration or a database, those require a backend and secure authentication; they are not included in this static starter.

## Deploy
This is a static site and can be deployed to providers such as Vercel, Netlify or GitHub Pages. Upload the folder or connect a repository. Configure the domain in your hosting provider's dashboard.
